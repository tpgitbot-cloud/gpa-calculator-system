# 🚀 QUICK START - GPA Calculator

Get started in **3 minutes**!

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

Open: **http://localhost:3000**

## Test

1. Create a simple Excel file (.xlsx):

| Student Name | Register Number | Subject1 | Subject2 |
|-------------|-----------------|----------|----------|
| John        | REG001         | O        | A        |
| Jane        | REG002         | A+       | B+       |

2. Upload the file
3. Enter credits: 4 for each subject
4. See your GPA results!

## Deploy

Push to GitHub, connect to Vercel, done! ✅
